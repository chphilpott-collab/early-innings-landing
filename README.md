# Early Innings Training - Landing Page

This is the landing page for Early Innings Training, an async video coaching subscription for youth baseball players.

## Project Structure

```
/
├── index.html          # Main landing page
├── images/             # Image assets (hero, coach photos, etc.)
├── .gitignore          # Git ignore rules
└── README.md           # This file
```

## Image Placeholders

The HTML contains placeholder image URLs. Replace these with your actual images:

- **Hero background:** Update the `background-image` URL in the hero section
- **Coach photos:** Three photo placeholders in the "About Coach Cole" section

## Deployment

This repo is connected to Vercel. Push changes to main branch and Vercel will auto-deploy.

## Domain

Connected to: `earlyinning.training`

## Quick Start

1. Add your images to the `images/` folder
2. Update the image URLs in `index.html`
3. Commit and push to GitHub
4. Vercel deploys automatically
